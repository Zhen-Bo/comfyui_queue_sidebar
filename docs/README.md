# Documentation

Project documentation for **ComfyUI Queue Sidebar**. Diagrams are written in Mermaid so they
render natively on GitHub and version alongside the code.

## Specification & Architecture

| Doc | What it covers |
|---|---|
| [SPEC.md](./SPEC.md) | What the extension does — goals, use cases, functional & non-functional requirements, data contracts, glossary. |
| [ARCHITECTURE.md](./ARCHITECTURE.md) | How it's built — C4 context/containers, module dependencies, execution sequence, task state machine, data flow. |

## Conventions

- **Diagrams:** Mermaid, embedded in the relevant doc.
- **Language:** English (matches `README.md`, code, and `locales/`).
- **Versioning:** `X.Y.Z`, no `v` prefix.
